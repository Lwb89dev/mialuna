# Attribuzioni di terze parti

Mialuna è resa possibile da questi progetti open source.

## Dipendenze dirette (pub.dev)

| Pacchetto | Licenza | Uso |
|---|---|---|
| flutter_riverpod | MIT | State management |
| go_router | BSD-3 | Navigazione |
| web_socket_channel | BSD-3 | Connessioni relay Nostr |
| crypto | BSD-3 | SHA-256 (id eventi, Blossom) |
| bip340 | MIT | Firme Schnorr BIP-340 (NIP-01) |
| pointycastle | MIT + Bouncy Castle | ECDH/AES per NIP-04 |
| http | BSD-3 | Blossom, LNURL |
| image_picker | Apache-2.0 | Selezione foto/video |
| video_player | BSD-3 | Riproduzione video |
| flutter_secure_storage | BSD-3 | Storage cifrato delle chiavi |
| shared_preferences | BSD-3 | Impostazioni, bookmark, mute |
| path_provider | BSD-3 | Cache locale |
| cached_network_image | MIT | Immagini del feed |
| url_launcher | BSD-3 | Apertura wallet Lightning |
| intl | BSD-3 | Formattazione |
| flutter_launcher_icons (dev) | MIT | Generazione icone |

## Icona

L'icona di Mialuna è un'illustrazione originale del progetto (camera su un
muretto con la luna riflessa nella lente). Non ridistribuirla come logo di
altre app senza attribuzione.
